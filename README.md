Shopify Sales Dashboard

## Project Overview
This project is a **Power BI report** created to analyze Shopify sales data and present the information through an interactive dashboard.

The report uses Shopify data along with a **Date dimension** to support sales analysis and time-based reporting.

## File
- `pbi_task3.pbix` – Power BI report file

## Data Model
The report contains:
- **Shopify data** – main business/sales data
- **Dim_Date** – date dimension used for date-based analysis

## Key Objectives
- Analyze Shopify sales data
- Understand sales performance using Power BI visualizations
- Perform time-based analysis using the date dimension
- Present business information in an easy-to-understand dashboard
- Practice data modeling and dashboard creation in Power BI

## Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Modeling
- DAX
- Data Visualization

## Dashboard Features
The Power BI report is designed to support:
- Sales performance analysis
- Product/business data analysis
- Date-wise analysis
- Interactive filtering and exploration
- Visual representation of business data

## How to Open the Project
1. Install **Microsoft Power BI Desktop**.
2. Download or clone this project.
3. Open `pbi_task3.pbix` using Power BI Desktop.
4. Refresh the data if required.
5. Explore the report and its visualizations.
